# Calculo média #
## Calcular média dos alunos ##

***

## Tecnologias Utilizadas ##
* Python 

***

### PASSO A PASSO ###

* Siga os passos abaixo para rodar o código na sua máquina: 

Certifiqui-se de ter o Python instalado no seu computador.

Abra o terminal (ou prompt do comando) na pasta onde o arquivo foi salvo.

Execute o seguinte comando:

Python calculadora notas.py

***

# Exemplo de uso # 

1. **Primeiro Passo** Digite a primeira nota 

2. **Segundo Passo** Depois digite a segunda nota quando solicitado

3. **Terceiro Passo** Confira o resultado no terminal!

***

# Funcionalidades 

- Entrada interativa: solicita as notas do aluno diretamente pelo terminal.
- Cálculo preciso: utiliza uma função para calcular a média aritmética das notas.
- Formatação amigável: exibe a média final arredondada para duas casas decimais.
- Verificação de status: verifica automaticamente se a média é igual ou superior a 7,0 para definir *APROVADO* ou *REPROVADO*.
